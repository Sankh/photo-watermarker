# 照片批量水印工具 · 使用说明（v3.0）

一个完全本地运行的小工具：读取照片 EXIF 信息，把拍摄时间、相机参数等以水印形式压到画面角落。照片不会上传到任何地方。

- 程序：`PhotoWatermark.exe（或目录版 PhotoWatermark\PhotoWatermark.exe）`（双击即用，无需安装）
- 源码：`照片水印_v2.1.py`（同目录，装了 Python 也可以用 `启动.bat` 运行）
- 老版本：旧版本 exe 保留在原目录，随时能退回

---

## 三步走

### ① 选照片

点左上角 **浏览…**，可以：

- 选一个**文件夹**（把里面所有照片加进来）
- 或者选若干张**照片文件**（多选）

选完自动开始读取，列表里逐行显示：文件名、拍摄时间、曝光、焦距、相机、GPS，以及「将添加的水印」预览。勾选 **包含子文件夹** 会连子目录一起扫（自动跳过上一次生成的「水印输出」目录，不会重复处理）。

> 读不到拍摄时间的照片（比如微信/QQ 压缩过的图、截图）在水印那一列是空的，写入时会原样复制，不会硬写错误信息。

### ② 核对与调整

列表下方一排胶囊按钮就是**水印内容**：

| 按钮 | 内容 | 默认 |
|---|---|---|
| 拍摄日期 | 2026-10-11 | ✔ |
| 具体时间 | 11:23 | ✔ |
| 光圈 / 快门 / ISO / 焦距 | f/2.8 · 1/250s · ISO100 · 50mm | 空 |
| 拍摄地点 | 优先用「地点显示文字」，没填就用 GPS 坐标 | 空 |
| 相机型号 | SONY ILCE-7CM2 | 空 |
| 自定义文本 | 点开会弹窗输入（如「2026 国庆 · 家里小院」） | 空 |

想**单张改水印**：双击表格里那一行的「将添加的水印」，改完点保存；这行的状态列会变成 ✎（已单独修改）。点「恢复自动」可以退回按规则自动生成。

右侧 **水印设置**：

- **排版与位置**：单行 / 多行；九个位置预设（四角、四边中点、居中）；或者选「自定义坐标」再填横向 / 纵向百分比。
- **外观**：字号（占照片高度 %，默认 1.5）、字体、字体颜色、不透明度、文字描边。
  - 字体有 16 款常用字体，外加两款复古相机液晶管字体：**液晶 · 7 段（相机日期）**、**液晶 · 14 段（字母齐全）**。
  - 液晶字体只含数字、英文字母和常用符号，**不显示中文**——用它们时水印里就别放中文，否则会出现方块。
  - 「文字描边」会自动选和字色相反的描边颜色，深色背景用白字、浅色背景用深色字都清楚。
- **输出**：默认在原文件夹下新建「水印输出」；也可以指定别的文件夹。JPEG 质量默认 100；保留原 EXIF 默认开；「移除 GPS」会把定位信息从输出里删掉。

### ③ 正式写入

点右上角 **开始批量添加水印**。顶部地址栏会变成一条进度条（处理中 5 / 80），底栏显示当前文件。写完会弹窗说「完成：已处理 N 张」。点「预览选中」能直接看这一张实际的水印效果。

**预览窗口**：滚轮滚动，Ctrl+滚轮缩放，←/→ 换图，Esc 关。底部一排图标按钮从左到右是：上一张、下一张、适应窗口、1:1、放大、缩小、关闭。图标按钮悬停 2 秒会显示中文名称。

## 常见问题

**1. 打不开 / 杀软报警**
exe 是 PyInstaller 打包的，部分杀软会误报，加白名单即可。首次启动要解包，慢 2–4 秒是正常的。如果 SmartScreen 拦了，点「更多信息 → 仍要运行」。

**2. 支持 RAW 吗**
不支持 .ARW/.CR2/.NEF 等 RAW，先把它们转成 JPG/TIFF。

**3. 地点只显示经纬度？**
是的，离线程序不会把 GPS 反查成「北京市朝阳区」。解决办法：把「地点显示文字」填上地名（比如「北京」），所有照片就用这个；或者对单张双击水印自行写。

**4. 输出会覆盖原图吗**
不会。默认写到原文件夹的「水印输出」子目录，原图完全不动；文件重名会自动加 _2、_3。

**5. 竖拍照片会不会躺倒**
会自动按 EXIF 方向转正再加水印，输出不带方向标记，任何看图软件都是正的。

## 版本

当前 **v3.0**。版本规则：小改动升小数点后的版本（v2.1 → v2.2），大改升大版本（v2 → v3），版本号写在文件名里，旧版本保留。

- v1.0：最初的扁平界面版
- v1.1：默认值调整、字段条件显示、单张改水印
- v1.2：字号按照片高度计算
- v2.0：字段胶囊移到列表下方、右侧分区标题加大、新增字体与字色、液晶字体
- v2.1：预览窗图标按钮（悬停 2 秒显示名称）、放大缩小 + Ctrl+滚轮、主界面按钮彩色化、地址栏进度条、底栏合并成一行、设置面板去滚动
- v3.0：性能重写（单张 1.9×、批量 5.2×、预览 2.4×、缩放 4×），线程改队列传递，推荐目录版启动
